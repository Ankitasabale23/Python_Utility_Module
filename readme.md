Python Utility Module

1. Objective

To create a reusable Python module containing common utility functions for validation, formatting, calculations, and file handling. The project demonstrates modular programming and code reusability.

2. Technologies Used

- Python
- "os" module
- "datetime" module
- Visual Studio Code

3. Features

- Email Validation: Checks whether an email has a basic valid format.
- Number Validation: Checks whether a value can be converted into a number.
- Currency Formatting: Formats amounts in Indian rupees.
- Percentage Calculation: Calculates percentages with validation for a zero total.
- Date Utility: Returns the current date in YYYY-MM-DD format.
- File Handling: Writes text to a file and reads its contents.
- Code Reusability: Allows utility functions to be imported into other Python programs.

4. Project Files

- "utility_module.py" – Contains reusable utility functions.
- "main.py" – Demonstrates the use of the utility functions.
- "sample.txt" – Created automatically when the program runs.

5. How to Run

1. Keep "utility_module.py" and "main.py" in the same folder.

2. Open the project folder in Visual Studio Code.

3. Open the terminal.

4. Run the following command:
   
   "python main.py"
   
   If Python is not recognized, run:
   
   "& "C:\Users\Admin\.local\bin\python3.14.exe" main.py"

5. Enter the requested email, amount, and marks.

6. View the results in the terminal.

6. Expected Output

The program validates the email and numeric inputs, formats the amount in rupees, calculates the percentage, displays the current date, and creates and reads a sample text file.

7. Conclusion

This project demonstrates Python modular programming, functions, input validation, exception handling, calculations, date formatting, and file operations. It improves code organization and makes functions reusable across multiple programs.
